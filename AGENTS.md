# Agent Instructions

## Documentation

All project documentation lives in `docs/`.

- `docs/README.md`: Documentation index and entry point.
- `docs/adrs/`: Architecture Decision Records.
- `docs/rfc/`: Proposals and design discussions.
- `docs/technical/`: Technical documentation and implementation details.
- `docs/user/`: User guides and functional documentation.

## Rules

- Read `docs/README.md` first when documentation is needed.
- Consult only documentation relevant to the task.
- Follow existing ADRs and accepted RFCs.
- Keep documentation updated when changes affect documented behavior or architecture.
- Avoid loading unrelated documentation to minimize token usage.
